To-Do List
A small To-Do List I made while learning how to work with functions and files in Python.
I wanted the tasks to stay after closing the program, so I started using a text file to save them. It was a big step for me back then. 
What it does
 • Add new tasks
 • View saved tasks
 • Remove tasks
 • Save tasks to a text file
 • Load them again when the program starts


How to run
[python todo_list.py](./03_todo_list.py)
About this project
This was an early Python practice project from the time I was learning how files worked. The code is simple, but I just wanted to keep it here.
